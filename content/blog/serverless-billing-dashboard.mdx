Serverless 按量付费上线后，用户对「花了多少钱、花在哪里」的需求也随之增长。近期我们在控制台与后端同步构建了完整的 **Serverless 账单体系**，让每一笔费用可追踪、可核对。

## 控制台账单功能

在 **个人中心 → 我的账单**（`/account/billing`）可查看：

- **日账单**：按天汇总 Serverless 费用
- **小时明细**：每小时的存储用量（GB）与对应费用

按量付费实例的消耗不再是一笔糊涂账，你可以按天回顾成本趋势，按小时定位异常波动。

## 试用期不计费

sqlpub-api（v0.0.59）优化了计费任务逻辑：

- 试用期内（默认 7 天）产生的计算与存储用量**跳过扣费**
- 控制台实例列表显示「按量计费（试用中，不收费）」
- 详情页展示试用到期时间（console-ui v0.5.3），到期后自动转入正常计费

这确保新用户可以安心完成兼容性测试与性能验证，不必担心试用期间产生意外费用。

## 后端账单模型

sqlpub-api（v0.0.58）新增三张账单表：

| 表 | 用途 |
| --- | --- |
| `serverless_hourly_usage` | 每小时存储用量快照 |
| `serverless_daily_bill` | 日维度费用汇总 |
| `serverless_billing_state` | 计费检查点，保障任务幂等与续跑 |

计费任务按小时采集用量、按天生成账单，支持断点续跑，避免重复扣费或漏扣。

## 钱包与欠费处理

- 按量付费实例通过 **钱包余额** 抵扣费用
- 余额不足时实例进入欠费锁定状态
- sqlpub-api（v0.0.60）新增 `UnLockPaygServerless` 定时任务：充值后自动解锁恢复正常服务

建议在控制台 **我的钱包** 保持充足余额，或开启余额预警（后续支持）。

## 付费类型一览

Serverless 实例目前支持三种计费类型：

| 类型 | 说明 |
| --- | --- |
| 按量付费 | 按 CU / 存储 / 流量实际用量计费 |
| 包年包月 | 固定月费，适合稳定负载 |
| 试用中 | 7 天免费试用，不计费 |

console-ui（v0.5.2）对付费类型展示做了统一优化，列表与详情页均可一眼识别当前计费状态。

## 成本优化建议

1. 试用期内充分压测，确认实例规格满足需求再转入付费
2. 定期查看日账单，关注存储增长趋势
3. 开发环境利用缩容至零，避免空闲计算费用
4. 持续高负载场景可评估包年包月是否更划算
