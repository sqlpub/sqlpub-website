## 如何新购

1. 登录 [SQLPub 控制台](https://console.sqlpub.com/user/login)
2. 进入 **共享实例-PostgreSQL**
3. 点击 **创建**，填写数据库名与用户名，选择区域与版本
4. 完成支付后系统自动开库；也可在列表中查看连接信息、重置密码、续费或释放

库名与用户名需符合平台命名规则（小写字母开头，字母 / 数字 / 下划线，长度有上下限），且不可使用系统保留名（如 `postgres`、`template0` 等）。

## 与其它产品的关系

- **共享实例-MySQL**：继续提供 MySQL 共享库，命名空间与 PostgreSQL 相互独立
