## Serverless 实例

Serverless 版提供**独享 MySQL 实例**，在控制台 **Serverless 实例** 菜单（`/dashboard/instance`）中管理。

### 创建实例

1. 进入 **控制台 → Serverless 实例**。
2. 点击 **创建**，填写实例名称与 MySQL 版本。
3. 创建前会展示计费说明：
   - 新用户 **免费试用 7 天**
   - 计算：0.045 元 / CU / 小时（按秒计费）
   - 存储：0.5 元 / GB / 月
   - 流量：0.5 元 / GB（50GB 免费 / 月，当前免费）

### 列表操作

| 操作 | 说明 |
| --- | --- |
| 编辑 | 修改实例名称 |
| 续费 | 包年包月实例可用 |
| 充值 | 按量付费实例，跳转钱包充值 |
| 删除 | 在允许的状态下删除实例 |

**计费类型：** 按量付费、包年包月、按量计费（试用中，不收费）。

**状态说明：** 待创建、创建中、正常、禁用、异常、欠费锁定、待冻结、冻结中、资源释放保护期、释放完成、待解锁、解锁中。

### 实例详情

路径：`/dashboard/instance/detail/:instanceId`

#### 基本信息

- 实例名称、公网连接地址
- 管理员账号与密码
- 状态、版本、实例规格（CU）、到期时间

#### 伸缩策略

- **缩放到零**：开关控制，空闲超时后缩容至零（默认 2 小时）
- **空闲超时时间**：可配置小时数
- **自动伸缩**：开关控制，按负载自动调整 CU
- **伸缩范围**：显示 vCPU / 内存上下限（最大 2CU）

#### 存储配置

- 存储类型（NAS / LOCAL / 云盘）
- 容量（GB），支持自动扩容

#### 监控信息

实时图表：CU、网络、CPU、内存、磁盘、QPS、命令数、连接数。

### 备份管理

路径：`/dashboard/instance/backup/:instanceId`

- 自动备份策略：**1 次 / 天**，默认保留 7 天
- 支持 **下载** 历史备份文件

### 续费与充值

- **包年包月实例**：`/dashboard/instance/renew/:instanceId`，¥9.9 / 月，年付享折扣
- **按量付费实例**：通过 **充值** 按钮为钱包充值，余额用于抵扣按量费用

### 绑定手机号

进入实例详情时，若未绑定手机号会提示绑定。
