

## 扩展数据库

共享实例（免费版 / 基础版）的资源配额固定，不支持手动扩缩容。Serverless 独享实例支持自动伸缩，在实例详情页查看与管理。

### 共享实例

免费版与基础版的连接数、请求数上限固定；存储超量时免费版会被锁定（可升级基础版解锁），基础版超出部分按量扣费。详见[使用限制](/docs/limits)与[价格方案](/docs/pricing)。

- 需要更高配额：免费版可 **升级** 至基础版（`/upgrade`）
- 需要独享资源与弹性伸缩：迁移至 **Serverless 版**

### Serverless 自动伸缩

在 **Serverless 实例 → 详情**（`/dashboard/instance/detail/:instanceId`）查看伸缩策略：

| 配置项 | 说明 |
| --- | --- |
| 缩放到零 | 空闲超时后自动缩容至零，停止计算计费 |
| 空闲超时时间 | 默认 2 小时，可配置 |
| 自动伸缩 | 按负载自动调整 CU |
| 伸缩范围 | 最大 2CU（2 vCPU，8 GB RAM） |

详情页 **监控信息** 提供 CU、CPU、内存、磁盘、QPS、连接数等实时图表，便于观察负载变化。

### 存储扩容

Serverless 实例存储支持自动扩容，容量按实际使用在详情页 **存储配置** 中查看。

### 计费说明

- 计算：**0.045 元 / CU / 小时**，按秒计费
- 存储：**0.5 元 / GB / 月**
- 缩容至零后仅收取存储与流量费用

详见[价格方案](/docs/pricing)与[账号与账单](/docs/account-billing)。

### 注意事项

- 合理设置最大 CU 上限，避免异常流量导致费用失控。
- 缩容至零后冷启动需数秒，客户端应设置合理连接超时。
- 自动伸缩适合负载波动明显的业务场景。
