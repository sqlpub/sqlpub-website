

## 创建数据库

根据所选方案，在控制台的不同入口创建共享 schema 或 Serverless 独享实例。

### 快速指引

| 方案 | 控制台入口 | 详细文档 |
| --- | --- | --- |
| 免费版、基础版 | 共享实例 → 创建 | [共享实例](/docs/user-db) |
| Serverless 版 | Serverless 实例 → 创建 | [Serverless 实例](/docs/serverless-instance) |

### 共享实例（免费版 / 基础版）

1. 登录 [控制台](https://console.sqlpub.com/user/login)，进入 **共享实例**。
2. 点击 **创建**，填写数据库名称、用户、MySQL 版本、资源类型与节点区域。
3. 免费版立即创建；基础版需支付 <UserDbPlanPriceLabel planCode="Basic" /> 后创建。

用户获得的是共享实例上的 **1 个独立 schema**。详见[共享实例](/docs/user-db)。

### Serverless 独享实例

1. 进入 **Serverless 实例**，点击 **创建**。
2. 填写实例名称与 MySQL 版本，确认计费说明后创建。
3. 新用户可享受 7 天免费试用。

详见 [Serverless 实例](/docs/serverless-instance)。

### 创建后

- 共享 schema：在共享实例 → **详情** 查看连接信息
- Serverless 实例：在实例 **详情** 查看连接地址与管理员账号
- 连接查询：参见[连接数据库](/docs/connect-database)、[驱动连接教程](/docs/driver-connect)与 [Web SQL 客户端](/docs/web-client)
