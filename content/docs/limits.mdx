## 使用限制

SQLPub 根据不同价格方案设定资源与操作限制，以保证平台稳定性和性能。详见[价格方案](/docs/pricing)。

### 实例类型

- **免费版、开发版**：共享 MySQL 实例，每位用户获得 1 个独立 **schema**，数据与其他用户隔离。
- **Serverless 版**：独享 MySQL 实例，可创建多个数据库，资源独立分配。

### 免费版（共享实例）

| 项目 | 限制 |
| --- | --- |
| 实例类型 | 共享实例 |
| 数据库 | 1 个 schema |
| 存储空间 | 0.5GB，超出后锁定（可升级开发版自动解锁） |
| 并发连接 | 30 个 |
| 请求数 | 3.6 万次 / 小时 |
| 公网流量 | 5G / 月 |

### 开发版（共享实例）

| 项目 | 限制 |
| --- | --- |
| 实例类型 | 共享实例（优质资源池） |
| 数据库 | 1 个 schema |
| 存储空间 | 1GB（超出按 0.35 元 / GB / 月计费，需保持余额充足） |
| 并发连接 | 50 个 |
| 请求数 | 7.2 万次 / 小时 |
| 公网流量 | 10G（超出按 0.7 元 / GB 计费，当前免费） |
| 自动备份 | 1 次 / 天，保留 3 个 |

### Serverless 版（独享实例）

| 项目 | 限制 |
| --- | --- |
| 实例类型 | 独享实例 |
| 数据库 | 无个数限制 |
| 并发连接 | 最大 3000 个 |
| 计算资源 | 自动扩展至 2CU（2 vCPU，8 GB RAM） |
| 缩容 | 2 小时无使用自动缩放到 0 |
| 存储 / 流量 | 按实际使用计费，见[价格方案](/docs/pricing) |

### 存储超量处理

共享实例的存储超量策略因方案而异，请在详情页用量环图中关注 **存储使用量**。

| 方案 | 包含额度 | 超出后行为 | 恢复方式 |
| --- | --- | --- | --- |
| 免费版 | 0.5GB | 数据库进入 **禁用（锁定）** 状态，无法写入 | 清理数据使用量回落至额度内，或 **升级至开发版** 后自动解锁 |
| 开发版 | 1GB | 超出部分按 **0.35 元 / GB / 月** 从钱包余额扣费 | 保持 **我的钱包** 余额充足；余额不足时可能被锁定 |

**免费版锁定说明：**

- 存储超过 0.5GB 后，数据库状态变为禁用，连接与写入将受限。
- 升级至开发版（共享实例 → **升级**）并完成数据迁移后，系统会自动解锁，同时获得 1GB 基础额度与按量计费能力。
- 若暂不升级，需删除或归档数据，使存储回落至 0.5GB 以内后恢复使用。

**开发版按量计费说明：**

- 存储在 1GB 以内不产生额外存储费用。
- 超出 1GB 的部分按 0.35 元 / GB / 月计费，从账号钱包余额中扣除。
- 请定期在 **个人中心 → 我的钱包** 充值，确保余额充足，避免因欠费导致数据库被锁定。
- 可在详情页用量环图实时查看当前存储占用。

### 通用限制

- **单表行数**：建议不超过 10,000,000 行。
- **大型查询**：建议使用分页或批量处理，避免长时间占用连接。
- **API 调用**：高频调用请做好节流，避免触发限流。
- **共享实例**：免费版与开发版共用物理实例，高峰期可能受到邻居负载影响；对隔离性要求高的场景请选择 Serverless 独享实例。

### 注意事项

- 请根据业务需求选择合适的方案，详见[价格方案](/docs/pricing)。
- 及时监控存储、连接数与流量使用情况，避免免费版存储超量被锁定或开发版因余额不足被锁定。
- Serverless 独享实例缩容至零后，下次连接可能需要数秒冷启动，请合理设置客户端超时。

### 小结

了解各方案的实例类型、限制与计费规则，有助于在性能、隔离性与成本之间取得平衡。
