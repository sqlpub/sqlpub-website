## 使用限制

SQLPub 根据不同价格方案设定资源与操作限制，以保证平台稳定性和性能。详见[价格方案](/docs/pricing)。

### 实例类型

- **免费版、开发版**：共享 MySQL 实例，每位用户获得 1 个独立 **schema**，数据与其他用户隔离。
- **Serverless 版**：独享 MySQL 实例，可创建多个数据库，资源独立分配。

### Serverless 版（独享实例）

| 项目 | 限制 |
| --- | --- |
| 实例类型 | 独享实例 |
| 数据库 | 无个数限制 |
| 并发连接 | 最大 3000 个 |
| 计算资源 | 自动扩展至 2CU（2 vCPU，8 GB RAM） |
| 缩容 | 2 小时无使用自动缩放到 0 |
| 存储 / 流量 | 按实际使用计费，见[价格方案](/docs/pricing) |

### 通用限制

- **单表行数**：建议不超过 10,000,000 行。
- **大型查询**：建议使用分页或批量处理，避免长时间占用连接。
- **API 调用**：高频调用请做好节流，避免触发限流。
- **共享实例**：免费版与开发版共用物理实例，高峰期可能受到邻居负载影响；对隔离性要求高的场景请选择 Serverless 独享实例。

### 注意事项

- 请根据业务需求选择合适的方案，详见[价格方案](/docs/pricing)。
- 及时监控存储、连接数与流量使用情况，避免免费版存储超量被锁定或开发版因余额不足被锁定。
- Serverless 独享实例缩容至零后，下次连接可能需要数秒冷启动，请合理设置客户端超时。

### 小结

了解各方案的实例类型、限制与计费规则，有助于在性能、隔离性与成本之间取得平衡。
