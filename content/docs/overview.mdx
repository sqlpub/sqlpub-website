## SQLPub 概览

欢迎使用 SQLPub，一个 Serverless MySQL 平台，让您轻松部署和扩展 MySQL 数据库。

### 核心功能

- **极速部署**：几秒钟即可启动新的数据库。
- **无服务器弹性扩缩**：根据工作负载自动调整资源。
- **按秒计费**：仅为实际使用的资源付费。
- **高可用性**：内置复制和故障转移机制。
- **默认安全**：TLS 加密、安全认证和基于角色的访问控制。

### 快速开始

1. 注册并登录 [SQLPub 控制台](https://console.sqlpub.com/user/login)。
2. 在 **共享实例** 或 **Serverless 实例** 创建数据库。
3. 通过 **连接数据库**、MySQL 客户端或应用驱动连接（参见[驱动连接教程](/docs/driver-connect)）。
4. 开始创建表并执行 SQL 查询。

详细操作请参阅[控制台指南](/docs/console)。

### 使用场景

- 需要可扩展关系型数据库的 SaaS 应用。
- MySQL 分析型工作负载。
- 需要即时数据库的开发和测试环境。

### 价格方案

SQLPub 提供**免费版**、**基础版**（<UserDbPlanPriceLabel planCode="Basic" />）和 **Serverless 版**（按量付费）三种方案：

- **免费版、基础版**：**共享实例**模式，用户申请获得 1 个独立 schema，适合个人项目与长期运行的轻量应用。
- **Serverless 版**：**独享实例**模式，独立 MySQL 实例，支持多数据库与自动伸缩，适合生产环境。

完整价格与功能对比请参阅[价格方案](/docs/pricing)，或在[价格页面](/pricing)查看。

### 总结

SQLPub 致力于通过提供完全无服务器的体验来简化数据库管理，实现可预测的性能和成本效率。
