## 备份与恢复

SQLPub 为开发版共享 schema 和 Serverless 独享实例提供自动备份，可在控制台下载备份文件。

### 开发版（共享实例）

路径：**共享实例 → 备份管理**（`/dashboard/userDb/backup/:id`）

| 项目 | 说明 |
| --- | --- |
| 适用方案 | 仅开发版 |
| 免费版 | 不支持，页面提示升级 |
| 备份策略 | 1 次 / 天，保留多个备份 |
| 操作 | 查看备份列表，**下载** 备份文件 |

### Serverless 版（独享实例）

路径：**Serverless 实例 → 备份管理**（`/dashboard/instance/backup/:instanceId`）

| 项目 | 说明 |
| --- | --- |
| 备份策略 | 1 次 / 天，默认保留 7 天 |
| 操作 | 查看备份列表，**下载** 备份文件 |

### 注意事项

- 备份由系统自动执行，控制台暂不支持手动触发备份。
- 下载链接为临时签名 URL，请及时保存到本地。
- 恢复数据需自行导入备份文件，或通过 SQL 客户端执行恢复操作。
- 重要数据请结合业务需求制定额外的灾备策略。
