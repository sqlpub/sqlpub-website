## 账号与账单

在个人中心（`/account`）管理账号信息、钱包余额、订单记录与 Serverless 账单。

### 基本信息

路径：`/account/base`

- 查看注册邮箱、手机号（只读）
- 修改昵称
- 上传头像（JPG / PNG，小于 2MB）

### 我的钱包

路径：`/account/wallet`

- 查看账号余额
- 点击 **充值** 跳转 `/recharge`，支持预设金额（¥10 / 20 / 50 / 100）或自定义（最低 ¥1）
- 余额可用于：开发版创建/升级、**开发版存储超量按量扣费**、Serverless 按量付费抵扣

开发版存储超过 <UserDbPlanValue planCode="Developer" field="storage" /> 后，超出部分按 <UserDbPlanValue planCode="Developer" field="overage" /> 从钱包余额扣除。请保持余额充足，避免因欠费导致数据库被锁定。详见[使用限制](/docs/limits)。

### 我的订单

路径：`/account/order`

查看历史订单，类型包括：

| 订单类型 | 说明 |
| --- | --- |
| 数据库订阅 | 开发版创建、续费、升级 |
| Serverless 订阅 | Serverless 包年包月 |
| 钱包充值 | 账号余额充值 |

订单状态：未支付、已支付、支付失败、取消支付、已退款。

### 我的账单

路径：`/account/billing`

面向 Serverless 按量付费用户：

- **日账单**：按天汇总费用
- **小时明细**：存储用量（GB）与费用明细

### 账号安全

路径：`/account/security`

- **修改密码**：通过邮件验证码重置
- **注销账号**：提交账号注销申请

相关入口：[密码重置](https://console.sqlpub.com/user/forgotPassword)、[账号注销](https://console.sqlpub.com/account/security)

### 密钥管理（API Key）

路径：`/account/apikey`

- 创建、编辑、启用、禁用 API Key
- 权限范围：query（查询）、execute（执行）
- 页面内嵌 API 调用示例

API 基础地址：`https://api.sqlpub.com/api/v1`

详见 [API 文档](/docs/api)。

### 支付方式

| 场景 | 支付方式 |
| --- | --- |
| 开发版创建 / 升级 | 微信支付、余额支付 |
| 开发版续费 | 微信支付、支付宝 |
| Serverless 包年包月续费 | 微信支付、支付宝 |
| 钱包充值 | 微信支付 |
