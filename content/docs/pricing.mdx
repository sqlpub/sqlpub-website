## 价格方案

SQLPub 提供三种方案，从免费起步，随业务增长无缝升级。所有方案均支持标准 MySQL 协议。

### 实例类型说明

SQLPub 提供两种实例模式：

| 模式 | 适用方案 | 说明 |
| --- | --- | --- |
| **共享实例** | 免费版、开发版 | 多个用户共用同一 MySQL 实例，每位用户申请获得的是独立的 **schema**（逻辑数据库），数据相互隔离 |
| **独享实例** | Serverless 版 | 每位用户拥有独立的 MySQL 实例，可创建多个数据库，资源独享、弹性伸缩 |

### Serverless 版

**按量付费** — 生产级弹性伸缩，用多少付多少。**独享实例**，资源不与他人共享。

**计费项：**

| 项目 | 价格 | 说明 |
| --- | --- | --- |
| 计算费用 | 0.045 元 / CU / 小时 | 自动伸缩，按秒计费 |
| 存储费用 | 0.5 元 / GB / 月 | 按实际使用 |
| 流量费用 | 0.5 元 / GB | 50GB 免费 / 月，当前免费 |

**功能特性：**

- 独享 MySQL 实例，可创建多个数据库，无 schema 个数限制
- 最大 3000 个连接
- 自动扩展至 2CU（2 个 vCPU，8 GB RAM）
- 2 小时不使用自动缩放到 0
- 私有网络 / IP 限制（后续支持）
- 99.9% SLA

### 如何选择

| 场景 | 推荐方案 |
| --- | --- |
| 学习、个人小项目 | 免费版（共享实例 + 1 个 schema） |
| 长期运行的个人应用 | 开发版（共享实例 + 更高配额） |
| 需要独享资源、多数据库 | Serverless 版（独享实例） |
| 流量波动大、需弹性伸缩 | Serverless 版（独享实例） |

### 升级与购买

1. 登录 [SQLPub 控制台](https://console.sqlpub.com/user/login)。
2. **开发版**：共享实例 → 创建，选择开发版并支付。
3. **免费版升级**：共享实例 → 升级，或访问 `/upgrade?dbId=...`。
4. **Serverless 版**：Serverless 实例 → 创建。

操作细节请参阅[控制台指南](/docs/console)、[共享实例](/docs/user-db)与 [Serverless 实例](/docs/serverless-instance)。

需要更高规格或企业定制方案，请[联系销售](/contact-sales)。
