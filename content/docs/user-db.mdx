## 共享实例

免费版与开发版使用**共享实例**，用户在控制台 **共享实例** 菜单（`/dashboard/userDb`）中管理自己的 schema。

### 创建数据库

1. 进入 **控制台 → 共享实例**。
2. 点击 **创建**，在弹窗中填写：
   - 数据库名称、数据库用户
   - MySQL 版本（8.4 / 8.0）
   - 资源类型：免费版 或 开发版
   - 节点区域：中国 / 新加坡（海外节点仅开发版可用）
3. **免费版**：确认后立即创建（每账号限 1 个）。
4. **开发版（<UserDbPlanPriceLabel planCode="Developer" />）**：选择微信支付或余额支付，支付成功后自动创建并跳转详情页。

### 列表操作

在共享实例列表中，每条记录支持：

| 操作 | 说明 |
| --- | --- |
| 详情 | 进入基本信息与用量页面 |
| 重置密码 | 生成随机新密码 |
| 续费 | 开发版可用；免费版无需续费 |
| 连接数据库 | SSO 跳转 Web SQL 客户端 |
| 升级 | 仅免费版，跳转升级页面 |
| 删除 | 永久删除，不可恢复 |

**状态说明：** 正常、禁用（超限/欠费/违规/到期）、临时解锁、升级准备中、迁移数据中、升级异常。

### 基本信息（详情页）

路径：`/dashboard/userDb/detail/:id`

详情页展示：

- 公网连接地址、数据库名称、账号、密码
- 状态、版本、节点区域、资源类型
- 创建时间、到期时间（开发版）
- **连接数据库** 按钮
- **释放连接数**：一键释放所有活跃连接
- 用量环图：当前连接数、存储使用量、请求数使用量

应用开发可使用各语言 MySQL 驱动连接，详见 [驱动连接教程](/docs/driver-connect)。

免费版请求上限 <UserDbPlanValue planCode="Free" field="qph" />，开发版 <UserDbPlanValue planCode="Developer" field="qph" />。

### 存储超量

详情页用量环图可查看当前存储占用。超量后的处理因方案不同：

**免费版（<UserDbPlanValue planCode="Free" field="storage" />）：**

- 存储超过 <UserDbPlanValue planCode="Free" field="storage" /> 后，数据库将被 **锁定**（状态变为禁用），无法继续写入。
- **升级至开发版** 并完成迁移后，系统会 **自动解锁**，同时获得 <UserDbPlanValue planCode="Developer" field="storage" /> 基础额度。
- 也可通过清理数据使存储回落至额度内来恢复使用。

**开发版（<UserDbPlanValue planCode="Developer" field="storage" />）：**

- <UserDbPlanValue planCode="Developer" field="storage" /> 以内不收取额外存储费；超出部分按 **<UserDbPlanValue planCode="Developer" field="overage" />** 从钱包余额扣费。
- 请在 **个人中心 → 我的钱包** 保持余额充足，避免因欠费被锁定。
- 详见[使用限制](/docs/limits)与[账号与账单](/docs/account-billing)。

### 备份管理

路径：`/dashboard/userDb/backup/:id`

- **免费版**：提示备份功能在开发版中可用，可点击去升级。
- **开发版**：自动备份策略为 **1 次 / 天**，保留多个备份；支持 **下载** 备份文件。

### 续费

路径：`/dashboard/userDb/renew/:id`

- 选择续费月数（默认 12 个月）
- 支持微信支付、支付宝
- 显示原到期时间与续费后到期时间

### 升级（免费版 → 开发版）

路径：`/upgrade?dbId=...`

1. 在共享实例列表点击 **升级**，或详情页资源类型旁点击升级。
2. 支付 <UserDbPlanPrice planCode="Developer" /> 后系统自动执行数据迁移。
3. 迁移期间状态依次为：升级准备中 → 迁移数据中 → 正常（或升级异常）。
4. 若因 **存储超量被锁定**，升级完成后会自动解锁。

### 绑定手机号

开发版用户若未绑定手机号，进入详情页时会提示绑定，可前往 `/user/bindPhone` 完成。

### 小结

共享实例是免费版与开发版的核心管理入口，涵盖创建、连接、升级、续费、备份与日常运维。
