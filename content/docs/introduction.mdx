## SQLPub 介绍

欢迎使用 SQLPub，一个 Serverless MySQL 平台，让您轻松部署、管理和扩展 MySQL 数据库。

### 核心特性

- **极速启动**：几秒钟即可创建新的数据库实例。
- **弹性扩缩**：自动根据负载调整计算和存储资源。
- **按秒计费**：只为实际使用的资源付费。
- **高可用性**：内置复制与故障恢复机制。
- **安全可靠**：TLS 加密、访问控制及自动备份。

### 快速上手

1. 注册并登录 [SQLPub 控制台](https://console.sqlpub.com/user/login)。
2. 在 **共享实例** 或 **Serverless 实例** 创建数据库。
3. 点击 **连接数据库** 使用 Web SQL 客户端，或通过 MySQL 客户端或应用驱动连接（参见[驱动连接教程](/docs/driver-connect)）。
4. 开始创建表并执行 SQL 查询。

详见[控制台指南](/docs/console)。

### 使用场景

- SaaS 应用需要可扩展的关系型数据库。
- 数据分析或 BI 工作负载。
- 开发和测试环境快速创建数据库实例。
